# 验证

```powershell
dotnet run --project tests/Quire.Package.Tests.csproj -c Release
dotnet run --project tests/Quire.Package.Tests.csproj -c Release -- --large
```

控制台验证器无需测试框架依赖，任何失败均返回非零退出码。每个用例使用独立临时项目，并在结束时关闭句柄、清理文件。

2026-10-28，索引模式改为内部选项并新增公开 API 契约验证后，Release 常规测试 79/79 通过，耗时 9.1 秒。此前统一索引实现的完整测试（含四种压缩/加密组合的超 4 GiB 读取、验证与解包）82/82 通过，耗时 104.6 秒；本次 API 可见性调整未重跑大文件用例。覆盖：

- 八种Meta类型、明确类型标注、空数组、规范化编码、溢出及无效格式。
- YAML相对路径、多级prefix、严格配置项、忽略规则、孤立sidecar、重复映射。
- 压缩/未压缩、加密/公开四种组合的构建和完整校验。
- Meta-only覆盖、删除源文件保持继承状态、完整覆盖时Meta状态替换。
- 目录扫描、头部时间排序、相同时间的相对路径排序、Unicode路径。
- 文件与目录独立枚举、递归/直接子项、目录存在性、前缀边界、文件/目录同名、孤立 Meta-only、空集合和枚举生命周期。
- 七层包覆盖的枚举合并、元数据替换与继承、UTF-8 排序，常驻/分页/无页缓存路径。
- 公开 API 默认自动选择索引，仅公开预算与 `IsMerged` 等诊断；策略枚举不导出、策略选项不可公开访问，诊断属性、构造函数及解构签名不泄漏内部枚举。
- 内部 `Auto` / `Merged` / `PerPackage` 策略等价性、精确预算边界、零预算自动回退、内部强制模式失败及实际索引统计。
- 4096 字节路径、2047 层虚拟目录、根节点预算、构建计数与填充阶段取消后的句柄释放。
- 统一索引的并发查询、释放后已有枚举器的生命周期、查询零分配，以及分页无缓存时目录枚举避免扫描大量文件的 I/O 验证。
- `AssetReader` 位置保持、跨块与完整块读取、取消恢复、尾部与极大偏移；四种编码、两种后端均验证复用缓存后的同步零分配。
- 常驻索引下文件查询、原始数据同步 `ReadAt` 的零分配断言。
- 路径索引分页、跨保护页的Meta、缓存关闭。
- 同步/异步并发、取消后的继续读取、结果与流的生命周期。
- 内存映射、范围读取、缓冲上限、头部/Meta/内容损坏、截断。
- 源内容在扫描后变化、取消、未知Tag不发布产物或成功记录。
- 多分包共享Tag和时间、编码策略变化、零第三方程序集依赖及LZ4许可证。
- Quire 项目/程序集名称、默认 quire.project.yml、package 替代 build、单横线参数与帮助输出。
- 直接密码与环境变量密码、配置密码来源覆盖、密码不写入日志和构建状态。
- 八种 Meta 类型解包再打包、空 sidecar、浮点边界与转义、Unicode 路径。
- 1/8 并发解包结果一致、流式内容校验、增量覆盖、冲突/损坏/取消时清理暂存目录。
- 目标目录保护、Windows 路径别名与设备名、解包参数范围检查。
- init 多包完整配置、默认初始化目录、已有配置与文件保护。
- YAML 构建预算与块大小、PK.QUIRE magic、块大小变更产生补丁、旧格式 Tag 被拒绝。
- 进度按块更新、实际读写量、空构建与 Meta-only、历史记录校验、损坏/取消状态、窄终端与纯文本日志、stdout/stderr 分离。

大文件用例使用长度 `2^32 + 12345` 的稀疏**源文件**，四种编码组合均实际遍历全部内容进行摘要、构建、构建后的 Verify 和流式解包，并比较原始文件与解包文件的完整 SHA-256。未压缩包和解包文件实际超过 4 GiB，不依靠只伪造一个大偏移完成测试。验证 2 GiB/4 GiB 前后、文件尾、跨块表页，以及内存映射访问文件尾；解包时将完整缓冲读取上限设为 0，确保使用流式路径。

本次大文件四种组合分别耗时 28.6 秒、25.8 秒、21.2 秒、21.7 秒（原始、AES、LZ4、LZ4+AES）。这些数字包括构建、读取、校验、解包和摘要比较，是功能用例耗时。运行时应预留至少 10 GiB 可用临时空间；Windows 使用稀疏文件 API 创建源，其他平台依赖文件系统对扩展文件的行为。
